# 输出模板

## 输出语言规则

- 默认使用简体中文（`zh-CN`）输出，不跟随新闻源的语言自动切换。
- 用户明确指定其他输出语言时，以用户要求为准。
- 没有可靠或通行中文译名的专有名词、机构名、人名、产品名、报告名及标准缩写可保留英文。
- 有通行中文译名且原文有助于识别时，首次出现可采用“中文名（English Name/Abbreviation）”，后续使用中文名或缩写。
- JSON 输出中的说明性文本也使用简体中文；字段名保持 Schema 定义的英文形式。

## 时讯与分析写作原则

- 先写已核验事实，再写基于事实的经济含义；不得将推断写成新闻事实。
- 标题应交代主体、动作和关键变量；避免情绪化、预测性或交易指令式措辞。
- 新闻内容只包含来源摘要的必要信息：事件、数据、政策表态、时间与发布者。来源摘要不足时明确标注，不补全缺失数字或背景。
- 核心信号应说明增长、通胀、政策、流动性、供给或风险偏好中实际受影响的变量；无可靠证据时写“待基于已核验来源补充”。
- 关注资产只列与该事件存在明确传导关系的资产或资产类别；不把默认关注清单全部重复列出。
- 区分“已发生”“市场预期”“可能传导”和“待验证”，并使用简短、可核验的中文句子。
- 自动邮件遵循 `references/daily_email_agent_workflow.yaml`：`mode: deliver` 一步到位——抓取→标准化/去重→排序→LLM 分析→质量门（自动补信号、合成今日资讯主线 / 中美日官媒宏观背景 / 市场影响地图）→渲染并发送 MML。旧的「Runtime 草稿 + 外部 enrichment JSON 合并」流程已废弃。
- 发送前质量门槛：所有已核验重要新闻必须有核心信号；前五个主线候选必须经 Agent 确认主题；市场影响地图必须包含利率债、汇率、股票、商品和风险偏好五个字段。
- 今日资讯主线由 `daily.mainlines` 渲染。每条 `headline` 至少 35 字，写作格式为“结论标题 — 数据、传导与必要限定”；渲染器仅将分隔符前的结论标题加粗，并以 `supporting_item_ids` 绑定前五个已核验候选；不得再使用“代表标题（等 N 条）”替代宏观判断。
- 官媒宏观背景（中美日）由 `daily.macro_background`（`{CN,US,JP}` 文本）渲染为中、美、日各一小段；缺省时回退为该国官方标题按来源拼接。官方/政府/央行条目折叠进此段，不再逐条铺表。三段始终都在，缺失国家补「暂无最新官方动态」。
- 本周观察指标优先渲染 `daily.weekly_watchlist`。未提供时，Runtime 从已核验新闻的核心信号生成“验证：…”条目；不得保留空占位文本。

## 核心信号填写规范

- 数据发布：写明指标方向、关键数值、同比/环比与预期或前值（仅在来源提供时）。
- 政策事件：写明决定、措辞变化、政策工具及生效时间；不要把市场猜测写为政策决定。
- 事件冲击：写明供给、需求、融资、风险偏好或政策预期中的直接传导环节，并列出尚待验证的条件。
- 每条优先保留 1–3 个最重要信号，避免将新闻摘要机械复述为信号。

## 市场影响地图
- 利率与债券：基于增长、通胀、政策利率预期和流动性数据，分析收益率方向、曲线形态、久期及信用利差；说明基准情景、期限差异和反向风险。
- 汇率：基于相对增长、利差、国际收支、政策预期和风险情绪，分析主要货币方向与波动来源；说明关键假设、时间范围和可能失效条件。
- 股票与行业：区分指数、行业和企业盈利影响，分析收入、利润率、估值、融资成本和政策敏感度；不得用宏观方向替代企业基本面证据。
- 商品：基于供需、库存、美元、实际利率、运输和地缘风险，分析能源、贵金属及相关商品；区分短期冲击与中期再平衡。
- 非经济成分与市场传导：基于政治、监管、地缘、安全、供应链、自然灾害和公共卫生等非经济事件，分析其对政策预期、风险偏好、行业盈利和资产定价的间接传导路径。
- 金融风险与市场结构：基于信用利差、违约、银行体系、回购、货币基金、期权波动率、持仓、卖空、ETF 资金流和指数调仓，分析流动性、杠杆和拥挤交易对资产价格的影响。
- 风险偏好与资产配置含义：分析跨资产相关性、波动率、流动性和风险暴露变化，可说明非个性化的分散化、久期、行业或防御性资产含义，但不提供仓位比例、买卖指令或个人配置建议。

## 格式规则

- **分隔符**：板块间用 21 个星号 `*********************`（不是 3 个或短线）
- **重要性**：★★★（高）、★★（中）、★（低），写在表格第一列
- **资产方向**：偏利多 / 偏利空 / 中性偏多 / 中性偏空 / 中性 / 影响有限
- **研究口径**：采用 CFA/投行研究风格，使用数据、可复核事实和明确的传导逻辑；语气专业、谨慎，不夸大收益。
- **不确定性**：资料不足时明确写出数据来源、假设条件、缺失信息和结论可能失效的情景，不得用训练数据补全。
- **建议边界**：资产配置仅讨论非个性化的风险暴露和配置含义，不给出个人仓位、交易指令、收益承诺或投机建议。
- **禁止项**：不要自由增加板块（如"核心主线"、"资产影响汇总"），严格按模板
- **邮件格式**：markdown（`.md`），含 From/To/Subject 头
