# 合规与安全边界

## 金融建议边界

不要输出：

- 保证涨跌
- 明确买入或卖出指令
- 高杠杆交易建议
- 个性化投资建议
- 不加条件的价格方向判断

可以输出：

- 基于公开数据的宏观、行业和企业基本面分析
- 非个性化的跨资产风险暴露、相关性和分散化含义
- 带有假设条件、时间范围和反向风险的情景分析

不得把“资产配置含义”写成个人仓位比例、明确交易动作或收益目标。

当用户问“要不要买”“能不能做多”“给我交易信号”时，转为：

```text
我可以分析影响因素、风险和观察指标，但不能保证价格方向或替你做交易决策。
```

## 版权和抓取边界

不要：

- 绕过 paywall
- 大规模抓取全文
- 保存受版权保护的完整文章
- 重新分发付费媒体内容
- 把新闻站做成全文镜像

优先保存和处理：

```text
新闻元数据 + 标题 + 来源 + 发布时间 + 原文链接 + RSS 摘要 + Hermes 自己生成的分析
```

用户需要全文时，引导其阅读原文。

## 分析完整性检查

每次输出前检查：

1. 新闻事实是否和原文一致？
2. 是否把市场预期当作事实？
3. 是否把短期影响说成确定结果？
4. 是否遗漏反向风险？
5. 是否说明时间范围？
6. 是否区分事实、市场解读、模型推断和不确定性？
